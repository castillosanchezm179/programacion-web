## ⚙️ Requerimientos funcionales

Describen **lo que el sistema debe hacer**.

| ID | Nombre | Descripción | Prioridad |
|----|--------|-------------|-----------|
| RF-01 | Registro de usuarios | El sistema debe permitir que un usuario cree una cuenta con correo y contraseña. | Alta |
| RF-02 | Inicio de sesión | El sistema debe autenticar a los usuarios registrados y permitirles acceder a sus funciones. | Alta |
| RF-03 | Gestión de [entidad principal] | El sistema debe permitir crear, consultar, editar y eliminar [entidad principal]. | Alta |
| RF-04 | Búsqueda y filtrado | El sistema debe permitir buscar y filtrar la información por criterios definidos. | Media |
| RF-05 | Generación de reportes | El sistema debe generar reportes o informes exportables (PDF/Excel). | Media |
| RF-06 | Notificaciones | El sistema debe enviar notificaciones al usuario ante eventos relevantes. | Baja |
| RF-07 | Gestión de roles | El sistema debe diferenciar permisos entre administrador y usuario común. | Media |

## 🛡️ Requerimientos no funcionales

Describen **cómo debe comportarse el sistema** (calidad, restricciones y rendimiento).

| ID | Categoría | Descripción |
|----|-----------|-------------|
| RNF-01 | Rendimiento | El sistema debe responder a las solicitudes en menos de 3 segundos en condiciones normales de uso. |
| RNF-02 | Seguridad | Las contraseñas deben almacenarse cifradas y la comunicación debe realizarse mediante HTTPS. |
| RNF-03 | Usabilidad | La interfaz debe ser intuitiva, de modo que un usuario nuevo realice las tareas básicas sin capacitación. |
| RNF-04 | Disponibilidad | El sistema debe estar disponible al menos el 95 % del tiempo. |
| RNF-05 | Compatibilidad | El sistema debe funcionar en los navegadores modernos (Chrome, Firefox, Edge) y en dispositivos móviles. |
| RNF-06 | Escalabilidad | La arquitectura debe permitir aumentar usuarios y datos sin rediseñar el sistema. |
| RNF-07 | Mantenibilidad | El código debe estar documentado y organizado de forma modular para facilitar futuras modificaciones. |
| RNF-08 | Confiabilidad | El sistema debe realizar copias de seguridad periódicas de la información. |
